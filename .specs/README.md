# .specs/

Cada mudança relevante no serviço terá uma spec própria nesta pasta, contendo:

- **Contexto**: por que a mudança é necessária.
- **Tarefa**: o que deve ser feito, de forma objetiva.
- **Regras**: restrições e decisões específicas daquela mudança (além das regras gerais de `AGENTS.md`).
- **Definição de pronto**: critérios que confirmam que a tarefa está completa.

Esta pasta **não** entra automaticamente no contexto do agente. Ela só deve ser lida quando o agente for explicitamente instruído a consultar uma spec específica.
